# 🚀 RAG-анализатор договоров ООО "ФЛАЙ-НСК"
## Статус: Этап 2 завершен. Готово к Этапу 3 (FastAPI).

### 📋 Бизнес-контекст
Проект разрабатывается для юридического отдела и отдела закупок ООО "ФЛАЙ-НСК" (разработка гражданских БПЛА). 
Система анализирует пакеты документов поставщиков (Договоры, Спецификации, Due Diligence) и находит скрытые риски, токсичные условия, несоответствия сертификатов и скрытые дедлайны.

### 🏗 Архитектура текущего состояния (Этап 1 + Этап 2)
1. **Инжестия (Этап 1):** 
   - Парсинг PDF через `PyMuPDF` (fitz).
   - Умный чанкинг (1000 символов, overlap 100).
   - Извлечение метаданных из имен файлов (RegEx) + обогащение по содержимому (Content-Based Enrichment).
2. **Векторизация и FAISS (Этап 2):**
   - Эмбеддинги генерируются локально через `Ollama` (модель `bge-m3`, 1024 dim).
   - Векторное хранилище: `FAISS` (IndexFlatIP).
   - Разделение индекса и метаданных (паттерн ID Mapping).

### 📂 Структура папок
- `db/` - Сырые PDF-документы (Пакеты A, B.1, B.2, B.3).
- `rag_artifacts/` - Артефакты RAG (FAISS index, JSON с чанками и метаданными).
- `app/` - Исходный код бэкенда (будет заполнен на Этапе 3).
- `scripts/` - Скрипты инжестии и утилиты.
- `backups/` - Точки отката (Checkpointing).
